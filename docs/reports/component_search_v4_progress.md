## 本次细化的实施规则

以下细节来自 v4 留给实现阶段的选择，已落实到代码与测试，属于待效果实验的实施规则，并非已验证最优。

1. 候选池先取 BILL4 输出 100 个，再生成合法随机 100 个。包括 BILL4 内部试探在内的所有完整可行 exact 候选都尝试入档。按 genotype 去重，逐非支配层选择；层内按归一化拥挤度降序、原候选序打破并列。随机生成有既有尝试上限，不足唯一种群报错；正常 BILL4 已提供 100 个唯一解，无需额外补足。
2. 锦标赛使用出生子问题权重与一次冻结的当前种群尺度，两个父代不同；第二次小池可只剩一个成员。差异伙伴从其余池成员抽至多 4 个，并列选择较小种群索引。
3. 距离为 MS 不同位置比例与 OS 同一 Job 两次出现位置差的等权平均。OS 差值总和除以 $L(L-1)$，$L$ 为 OS 长度；空串距离为零。
4. 片段交叉从 $L+1$ 个边界抽两个不同边界，可覆盖整段，按另一父代次序填剩余次数。先后合并将两次出现映射为操作，反复随机取一个父代首个剩余操作并从两序列删除。非 Job 联动交叉的 MS 用独立 Job 掩码继承完整 P/D 对。
5. 插入排除原槽；块长固定 2、逆序长固定 4。重复标签可导致不变解，不重试。区域内双阶段要求 P/D 都换实例；同区路径交换抽至多 4 个伙伴，选择首个双向合法且不同者。
6. 负载代理为区域操作 `duration × compute` 之和除以实例数。在其他可行区域中按负载和区域索引排序，随机选前至多 3 区，再随机选区内合法路径。
7. TOU 代理从释放时刻无排队执行 P/D，异实例计 KV 延迟；按当前功率模型单操作运行功率跨电价段积分，除以 3600。不包括排队、其他任务干扰、需量和空闲尾段。按代理价及路径索引排序，随机取前至多 3 路径。缺少完整电价覆盖报错，不能有免费尾段。
8. 改善量排序冻结尺度；并列保留出生邻域次序。方向排序沿用现有方向关联，只排序出生邻域，不改变替换范围。
9. 末段保留原目标代表、物理时间表访问标记和新档案成员迭代。两端交替状态跨选择保存。拥挤度基于当前完整目标前沿，零范围维度不贡献，端点为无穷，Flow/Bill 升序打破并列，再从未访问目标中选取。

## 使用入口

运行前将 `PYTHONPATH` 指向本工作树的 `src`，防止共享虚拟环境导入其他工作树。

```powershell
$env:PYTHONPATH = (Join-Path (Get-Location) 'src')
python scripts/run_component_search_v4.py --export-space outputs/v4_space.json
python scripts/run_component_search_v4.py --instance INPUT.json --configuration CONFIG.json --calibration CALIBRATION.json --seed 1 --seconds 600 --output outputs/v4_result.json
```

配置文件是导出空间 `default` 对象的同结构字典，可只填写改动字段；不传配置使用默认点。校准文件须提供已选定实例折的校准对象（含现有算法要求的 `rho/h/w_cutoff`），入口不重新拟合或自动选折。实例功率模型原样读取，不转换。

`--generations 1` 仅用于本地接线检查，不能替代正式完整时间预算。输出包含完整配置、输入与校准 SHA256、计数、停止原因、种群及档案。目标文件存在则拒绝覆盖。

本入口执行单个配置并导出空间。后续 irace 接线已增加独立入口、固定 HV 评价包、竞赛恢复与验证选型，见 [irace 运行协议](../experiments/irace_component_search_v4.md)。组件实现批次本身未运行外层搜索；后续仅进行技术短测，不代表正式配置实验。
