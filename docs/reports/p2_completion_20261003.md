# P2 F6／CG／CT：720 次实验完成验收

2026-10-03，本地 P2 正式矩阵全部执行完成。原冻结入口的 `validate_complete` 对 720 次发布结果逐项验真通过，覆盖 240 个配对三组块。本文记录执行、完整性和复现条件；尚未进行 HV、IGD+、配对统计或机制效果分析，不能据此认为 CG／CT 优于 F6。

## 冻结设计

| 项目 | 实际执行 |
| --- | --- |
| 比较组 | F6 原算法；CG 普通基因型复制后 SSGS 重建；CT 基因型与完整时间表延续 |
| 候选概率 | CG／CT 为 20% 复制、80% 原变异；F6 使用原变异 |
| 实例 | 50／100 jobs 各 12 个 development 基础实例；H／T 两种电价 |
| 算法种子 | 1101、2202、3303、4404、5505 |
| 正式规模 | 24 个基础实例 × 2 个电价 × 5 个种子 × 3 组 = 720 次 |
| 配对条件 | 每块三组同一实例、初始种群、种子和主机；除输出位置与 offspring policy 外配置一致 |
| 引擎预算 | 50 jobs 为 600 秒，100 jobs 为 1200 秒；种群 100，时间预算软停止 |
| 调度 | 最多 16 个 solver；每个槽位依冻结顺序串行执行三组，六种组内顺序均衡 |
| 记录 | 三组统一轻日志；保留 final population、archive、Q-table、operator counters 和 anytime 数据 |

实际引擎累计 **180.2515 worker-hours**；这是 720 次引擎运行时间之和，不是用户等待时间。最终复验及导出累计约 **1,675 秒**，同样为各 worker 的累加值。最大单次预算超时 **11.319 秒**，属于软停止。日志报告的单 worker 峰值 RSS 最大约 **72.3 MiB**，中位约 **42.9 MiB**；这些值来自运行采样，不能代替连续监控或系统整体内存峰值。
