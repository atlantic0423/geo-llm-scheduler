# S4 三项消融与四篇 Trans 算法的 Python 适配

状态：本地研究实现；尚未在冻结 120 例上完成正式效果比较。本文说明可执行机制和适配边界，不能据此宣称重现了原论文成绩。

本文四组 S4 与四个 Trans 为首版工程规格。后续 seed 1 全面板批次增设 A4 直接右移及五个历史增强对照，实际运行设计见 [seed 1 十四配置](s4_seed1_panel.md)。

## 1. 用户确认的消融

以 `A0_FULL_S4` 为完整参考，仅有三项独立消融，不组合删减，不新增状态或奖励：

| 入口 | 唯一研究因素变化 | 保留内容 |
| --- | --- | --- |
| A0_FULL_S4 | 无 | BILL4、MOEA/D、Q1_NET、gamma=0.9、B3L3、无 P3 动作、S4 外置右移 |
| A1_NO_SHIFT | 整个外置右移模块关闭 | Q、原初始化、LS 算子和接受规则 |
| A2_RANDOM_OPERATOR | 删除 Q 表和更新，当前可用算子中均匀抽样 | 同样资格门、B3L3、接受规则、初始化、S4 右移 |
| A3_RANDOM_INIT | 初始 MS 为随机合法同区域 P/D 路径，OS 随机排列 | Q、B3L3、S4 右移和演化主干 |

所有配置总时间均包含初始化；LS 与外置右移共享原来的 20% 累积时间门。该门使用初始化后的搜索时间，不是每代固定给每个解 LS。每次 Q 运行从空表开始在线学习。完整 S4 保留原来的选解资格过滤、三区域分配和新鲜度策略，不把右移重新放回 Q 动作池。

同一实例/种子下，A0/A1/A2 的初始候选集合应一致。随机初始化节省下来的时间自然留给搜索，这是包含初始化的总墙钟比较的一部分。

## 3. 统一调度适配和公平口径

三种连续优化算法使用同一 `SearchContext`。默认 $4N$ 个有界键分别表示 $N$ 个合法同区域路径、$2N$ 个重复工件优先级、$N$ 个 Prefill 等待比例。排序优先级后得到 OS，SSGS 根据计算/显存资源允许并行加工。等待比例在当前 Prefill 起点和冻结 Decode 给出的合法上界之间取位置；资源不满足就保留该 Prefill 原位置，按工件编号依次检查，不按电费择优。

这个等待编码是通用的目标无关调度表示，不调用我们的 S4 选解、COMMON 联合平移、Q 或 BILL4。它能表达单 Prefill 延迟，但一次顺序修复不能保证表达任意联合平移；`--earliest-only` 提供 $3N$ 纯最早解码的明确研究选项，不能在正式矩阵里混用后仍称同一算法。

两个目标直接来自 exact evaluator：总 Flow 和 TOU+需量总账单，不替换为 makespan 或能耗。新增候选和被淘汰的完整精确候选都尝试进入统一观察档案。连续算法内生的种群/档案选择仍按原法执行，观察档案不反向指导其搜索。最早解码的中间候选也是一次完整精确评价，计入评价数并更新观察档案；每个连续向量查询因此可能产生两次精确评价。报告同时保留 adapter 查询数和 gateway exact 次数。

原连续算法的不可行解搜索在本项目可行解码器下退化为全可行分支。CMOFLCS 的“辅助种群全部不可行后切换角度约束”不可能触发，保留可达路径的双种群选择；不能把这项实验说成完整检验了原论文的困难约束处理优势。

运行时间从适配上下文/初始化开始，包含解码、修复、学习、代理、选择、档案更新。文件加载和结束后的独立 exact 审计不参与优化。按完整候选或阶段边界停机，并报告实际超时量。原方法以 FE/maxFE 表示进度的部分映射为已耗总墙钟比例；CMOFLCS 的 20000 次查询奖励重置仍遵循源代码的整除触发。

## 4. 逐法核对与数值边界

### CMOEA-CD

保留默认 SPEA2 距离截断。目标按 MATLAB half-away-from-zero 保留十位小数用于 DominationCal；重复点保留第一个。DA 在全可行情况下，锥内最小夹角或空锥回退都等于该方向的全局最小夹角，因此用等价的直接索引。保留 FA/FEA 不足时随机补齐、默认 N=100、每个来源 floor(N/3)。GA/DE 的多项式变异指数是此方法源码中的 1，不误用其他方法的 20。

### CMOEA-AOP

6 维状态依次是两个原始目标的样本方差、两个目标总和、总违反量、进度；没有擅自加状态归一化。3 维动作经平移和归一化成为各算子份额，每种算子至少产生 4 个子代。DDPG 使用 32/32 隐层、500 条重放、batch32、gamma0.99、tau0.005、actor/critic 学习率 1e-4/1e-3、原 OU 噪声和 Adam。此 gamma 是外部对比方法的参数，不是我们 Q1 的 0.9。

保留两处容易误“修正”的源码行为：重放存的是归一化份额，而 actor 的输出范围为 [-5,5]；下一次选动作使用 GenerateSample 返回的旧种群状态。DEBest 原代码的第三索引未排除第二索引，此处也保留。固定 MATLAB single 计算替换为 NumPy float64，随机数流不可与 MATLAB 位级相同。原始状态量纲可能导致 tanh 饱和，应该如实诊断，不暗中改成另一个 AOP。

### CMOFLCS

输入与输出隶属函数、18 条规则、min 蕴含/max 聚合、101 点重心计算均按源码/默认 Mamdani 机制实现。以进入第一种群的子代比例累加本次算子奖励；GAhalf 每种群 N/2 个子代，DE 每种群 N 个。收敛/多样性分母为零时原代码产生 NaN，此处取中性 0.5，作为显式的数值适配。尚未在 MATLAB Fuzzy Logic Toolbox 上逐点交叉执行，测试不是此种跨语言等价证明。

### PSLGP-H-PD

依据论文中的 HV 版本与 Algorithms 1–4，不照抄仓库中名称为 HV、却包含 `compare-criteria=GD`、`use-multi-criteria-selection=false` 的混合实验参数文件。保留默认 1000 个双树个体、最大深度 8、初始深度 2–6、80/15/5 交叉/变异/复制、七元锦标赛；一种树做子树交换，另一树整体交换。偏好终端在抽取中权重加倍。

原动态 FJSP 模拟器替换为本实例的 P/D dispatcher：顺序树选择下一个可派发工件阶段；路由树选择合法同区域 P/D 机器对。特征为 PT、READY、REMAIN、LOAD、COMPUTE、VRAM、ENERGY、PRICE、W1、W2。LOAD/READY 是已派发前缀代理特征，最终时刻由 exact SSGS 给出；不是把并行机器强行变为串行，也不声称这些特征与原车间终端完全等同。该版本不包含额外主动等待决策。

40 维 PC 来自固定的 20 个顺序和 20 个路由情境，情境内抽取 7 个候选；小玩具问题不足时重复填充。情境取自本实例的一次计时手工规则派发，而不是原文另生成的动态仿真实例，这是静态在线适配。参考规则排序在比较不同目标偏好时必须固定，否则规则与自身比较会总为第一名，掩盖真实偏好变化；有专门反例测试。每代更新参考双树。

主偏好精确评价，其余 100 个偏好使用当前代的 1-NN PC 代理，预测结果绝不写入 exact 档案。选择顺序为非支配层、HV、手工规则归一化加权和、偏好多样性。论文的式 (6) 写独特行为比例，但图/文字也出现平均距离；这里明确采用式 (6)。5N 子代通过下一代主偏好 PC 做 1-NN 预选择，半径 0、容量 1 的相同 PC 优先只保留一个，不足 N 时按排序补入被惩罚重复者。每代轮换主偏好；静态单实例没有原文的训练实例轮换，也没有免费离线训练或跨测试实例共用模型。

输出同时保留实际搜索档案、末代精确种群、每代最优双树。比较档案是本项目统一口径，不等同于论文用单个训练后规则在未见测试实例上生成的前沿。因此论文写作应称“PSLGP-H-PD 在线适配基线”，不能声称直接重现原文实验。GP 只在除数恰为零时返回 1，并对极端数值截断至有限范围，显式记录此浮点保护。

## 5. 本地执行

安装 `python -m pip install -e ".[dev,trans]"`。下载代码使用 `python scripts/download_trans_sources.py --output outputs/trans_upstream`，会核验固定 ZIP 哈希。

示例（shell 中自行填入实际文件路径，不修改实例）：

```sh
python -m geo_llm_scheduler.experiments.trans_runner --algorithm CMOFLCS_PD --instance INPUT.json --output OUTPUT --seed 16901 --seconds 1200
python -m geo_llm_scheduler.experiments.trans_runner --algorithm A0_FULL_S4 --instance INPUT.json --output OUTPUT --seed 16901 --seconds 1200 --calibration CALIBRATION.json --calibration-key n100_f0
```

没有显式时间时采用 50/100/200 任务 600/1200/2400 秒。默认实例仍是冻结 120 例；实际 manifest 位于 `outputs/mechanism_stress120_20261031/manifest.json`，其 `path` 字段指向 `instances/`。禁止重新生成或按效果筛掉实例。`--population` 和 `--max-generations` 仅供明确标记的工程验收，不作为正式对比默认。

每次输出包含配置、代码 SHA/工作树状态/源码哈希、实例哈希、种子、exact 档案和原生种群、trace、真实耗时、独立精确审计、文件 manifest。S4 各臂另保存逐步局部搜索与右移日志、最终 Q 表；随机算子臂的 Q 表明确为 null。已有输出目录禁止覆盖。

正式开跑前仍需冻结新 120 例的历史 Q 校准表映射及重复种子矩阵。入口要求明确提供校准记录，不会把玩具测试参数写成研究默认；本批工程验收临时使用历史同规模 f0，并明确标注这不构成新面板的冻结策略。
