# S4 与九个外部对照的 seed 1 全面板实验

固定 120 例，50、100、200 任务各 40 例，每次总墙钟 600、1200、2400 秒，包括初始化。14 配置各跑 120 次，共 1,680 次、2,352,000 秒。全部算法种子为 1，实例生成种子沿用冻结面板。以此批比较实例间表现，单种子不能估计同一实例上重复运行的波动。

完整 S4、整体去右移、随机可用算子替代 Q、纯随机初始化，以及新增 A4。外部四套近期方法和五个旧增强基线均采用[各自的既有实现](trans_python.md)。A4 使用 BILL4 和原 MOEA/D 搜索，共享初始化后的累计 20% LS 时间门。原档案种子采样器挑中的解直接进入一次 FAST COMMON 右移，不运行算子轨迹、不创建或更新局部 Q 表、不再从种群中重新抽取右移目标。沿用原右移内部候选、完整账单、冻结 Decode/Flow 的精确检验及档案/种群回流。对该解一次右移的前沿 HV 增益反馈给原种子采样器，每次调用计一个框架刷新步。此臂同时省去局部算子轨迹和右移前的二次选解；不能把相对 A0 的全部差异单归因于 Q，Q 对随机选择应看 A0/A2。

每次有学习的 S4 运行从空 Q 表开始。新实例沿用既有未见实例校准规则：每个规模按冻结实例 ID 排序交替使用该规模历史 f0、f1，各 20 例。所有配对臂共享映射，生成实例及既往/未来效果不参与分配。A2/A4 不使用学习值。五个旧对照是 EXTH 系列，BILL4+MOEA/D 另属历史独立对照。

单任务入口为 `trans_runner.run_case`。批次入口 `scripts/run_s4_panel.py` 密封输入/配置哈希、提交、完整配对矩阵；服务器预检独立初始化指纹及 exact。按任务时长排序，区组内轮换配置顺序。调度器保留已验真的完成任务，失败时停止新派发并让活动任务结束；每 worker 单线程绑定一颗物理核，总计 24 颗。每个运行保存正在前进的计数和前沿检查点、最终物理调度、实际耗时、初始指纹与逐文件校验。最终回收按本批原始 Archive 使用统一指标坐标比较。
