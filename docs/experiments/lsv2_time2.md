# B3L3 双倍时间配对实验

本批为开发筛选，不改默认算法。研究问题是：搜索时间翻倍后，Q1 NET G9 B3L3 是否优于动作池匹配的随机选择，删除 P3 是否改变这一关系。用户选择优先更多实例，不补第二个 seed。

## 矩阵与冻结设置

- 40 个实例，20/50/100/200 各 10 个；保留旧 32 个，再按设计编号增加每规模最小的两个未选编号，不依据历史效果排序。旧 dev/holdout 标签保留，新增标为 extension；extension 来自既有 stress64 池，不是全新盲测。
- 10 臂：Q1 NET G9 B3L3、同配置去 P3、UNIFORM B3L3、UNIFORM B3L3 去 P3、BILL+MOEA/D、增强 MOEA/D、NSGA-II、RK-MOPSO、SPEA2、epsilon-IBEA。
- 全部 seed 16901，400 次运行。每个 Q run 从空表在线学习，不做预训练。
- 原预算 $T$ 为 300/600/1200/2400 秒，本次 $2T$ 为 600/1200/2400/4800 秒，包含初始化。所有臂都延长，不仅延长 Q。
- Q 与随机控制使用相同 BILL4 初始化、variation、replacement、B3L3、LS 时间份额与 A8 门控，仅 selector 有差别；去 P3 同时从候选和 bootstrap 中移除 P3。Q 状态、净奖励、gamma 0.9 均不改。
- 五个增强对比算法保持原 hybrid 初始化和 Polish 机制。因此全算法对比是完整算法包比较，Q 对随机才是学习器的匹配比较。
- dev 复用原交叉拟合校准；各规模其余实例按固定编号次序交替复用原 f0/f1，不重新拟合，不把评估实例放进校准训练集。新增实例不用于调参。

## 时间点与预先规定的分析

保存最终前沿、初始解、可重放 archive insertion 事件、LS 步骤、Q 表及耗时。原时间点由时间戳不超过 $T$ 的有效 archive 事件重建；anytime 快照用于辅助检查，不能把超过阈值才触发的快照当作精确 $T$ 前沿。

这里的 $T$ 是 $2T$ 配置的运行前缀。时间份额与搜索进度可能依赖总预算，因此它不是独立运行 $T$ 配置的反事实，也不直接替代历史 $T$ 重跑。

每实例在全部方法、两时间点的公共参考集上计算相同归一化 HV 和 IGD+。主要比较有四项：

1. 保留 P3 时，$2T$ 的 Q−随机 HV 差。
2. 删除 P3 时，$2T$ 的 Q−随机 HV 差。
3. 保留 P3 时，Q 的 $T\to2T$ HV 增量减去随机的对应增量。
4. 删除 P3 时，同样的增量差。

按实例配对，报告均值、中位数、胜平负、区间与 Holm 校正后的配对检验；分别列规模和 dev/holdout/extension，勿只报最好的组。IGD+、目标极值、有效评价数、各步收益/开销、Q 访问数和动作份额是辅助解释。单 seed 能检验本批实例范围的趋势，不能证明跨种子稳定优势。

不额外添加 G0、DQN 或新策略；若 Q 仍不优于随机，保留负结果。
