# 前沿空隙繁殖分配（A1）与匹配对照（A0）

状态：研究路径，开发筛选；软件默认算法不变。实现见 `src/geo_llm_scheduler/experiments/gap_allocation.py`，批次入口 `scripts/run_gap_alloc.py`，待确认项见 `docs/reports/open_questions.md`。

## 动机

对 120 个 GS4 工作版运行的离线诊断见本地 `outputs/framework_review_20261113/REPORT.md`：

- 20%–31% 的子问题与其他子问题共用现任解；
- 最终前沿最大空隙占全部空隙面积的 33%–43%，指向它的权重射线只有 14%–19%；
- 最大空隙两端多为结构不同的解。

LS 中按空隙抽样起点是唯一稳健有效的选点规则，A1 把它搬到 MOEA/D 的繁殖调度上。

## 规则

每代开始，用档案前沿相邻点围成的空隙盒面积给子问题射线分配权重：

- 一个空隙的面积在穿过它的非重复射线之间均分；没有射线穿过的空隙归最近的射线；两端射线各得最大空隙面积的加成。
- 权重乘失败折扣 $0.5^{\min(k,10)}$，$k$ 为该子问题连续未入档的槽位数。
- 与均匀分布按 0.8/0.2 混合，再把单个子问题的份额截到 5%。
- 按该概率有放回地抽 100 个槽位。

A0 把同一概率向量随机置换到各子问题后再抽样。

## 判定（预注册）

- 对照：GS4；面板：120 例；种子：19、20；预算：默认 600/1200/2400 秒，含初始化。
- 主判定：A1 对 GS4、A0 对 GS4 在 100+200 任务合并后的配对 HV 差，中位数为正且 Holm $p<0.05$。
- 机制判定：A1 对 A0。
- 50 任务单独报告。

不声称：首创自适应分解，也不声称在其他预算或实例集上的效果。
