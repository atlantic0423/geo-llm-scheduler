# 前沿分段隔离（S3）与交错岛匹配对照（I3）

状态：研究路径，开发筛选；软件默认算法不变。实现见 `src/geo_llm_scheduler/experiments/segment_topology.py`，引擎新增可选 `topology` 接缝（省略时保持欧氏邻域和全种群交配池）。批次入口为 `scripts/run_segment.py`，待确认项见 `docs/reports/open_questions.md`。

## 动机

离线方差分解见本地 `outputs/variance_decomp_20261114/REPORT.md`，数据为 GS4 在冻结 120 例上的 5–7 个种子：

- 同一次运行的最终前沿，相邻点的区域分配几乎相同，相似度约 1.0；不同种子的前沿之间只有 0.33–0.41，接近随机置换基线 0.27。最终种群三段之间为 0.78–0.87。
- 多种子前沿并集比单次运行的平均 HV 高约 14%，比最好的单次高 3%–5%；并集前沿中最多一个种子贡献的点约占一半。
- 把同样的总预算切给多次独立运行（按检查点近似），在 100/200 任务上比单次运行差 4%–19%。

据此判断：MOEA/D 的邻域拓扑让一种区域分配沿整条权重链扩散，整条前沿只用一个结构；把时间切开去换结构多样性不划算。

## 规则

- **S3**：100 个子问题按权重顺序分成三段（33/34/33）。
  - 每个子问题的交配/替换邻域取本段内欧氏最近的 20 个权重。
  - 邻域概率抽签失败时，交配池取本段，不再取全种群。
  - LS 回流使用同样的分段邻域。
  - 档案、归一化和 LS 选点保持全局。
  - 不抽随机数。
- **I3**：按 $i \bmod 3$ 分成三组交错的岛，其余同 S3。隔离强度和组大小与 S3 相同，但每个岛都覆盖整条前沿，切断“段与前沿位置”的对应。

## 判定（预注册）

- **设置**：对照 GS4；面板 120 例；种子 21、22、23；预算为默认 600/1200/2400 秒，含初始化。
- **主判定**：S3 对 GS4、I3 对 GS4，在 100+200 任务合并（240 对）后的配对 HV 差。中位数为正且 Holm $p<0.05$ 才算支持。
- **机制判定**：S3 对 I3（同口径）。
- **机制指标**（不参与主判定）：
  - 最终前沿上区域级分配结构的个数；
  - 前沿相邻点区域相似度；
  - 最终种群三段之间的区域相似度。
  - 预期 S3 的段间相似度低于 GS4。
- **单独报告**：50 任务。

不声称首创多子种群分解。MOEA/D-M2M（Liu, Gu, Zhang, IEEE TEVC 2014）已经把目标空间分成子区域、各用一个子种群求解。本工作提供的是：分层调度问题中“结构塌缩”的诊断证据，以及区分“隔离”与“按前沿位置专门化”的匹配对照。也不声称在其他预算或实例集上的效果。
