# 初始化电费混合方案：夜间诊断协议

本批为用户授权的独立研究实验，目标是观察添加费用构造后固定100成员初始化的费用端与折中覆盖。默认初始化、MOEA/D、RL、SSGS和exact evaluator均不修改。所有实现结果只是技术验收，效果待正式数据分析。

## 构造及比例

| 家族 | 新个体的构造依据 | 两档比例 |
| --- | --- | --- |
| RESAMPLE | 原Random生成器，完整候选电费/Flow筛选，作为额外采样对照 | 10%、20% |
| TOU | 资源可行的实际前缀执行时段电价积分，含全实例idle | 10%、20% |
| DEMAND | 所有地域固定900秒窗口的前缀需量费用，尾窗分母仍900 | 10%、20% |
| BILL | TOU加需量费用，Flow权重0、0.1、0.25、0.5循环 | 10%、20% |
| PORTFOLIO | 复用TOU、DEMAND、BILL库，交替分配新配额 | 10%、20% |

原十类按各9或8成员保留，再加入10或20个新成员。总比例100%，成员数100，全部genotype唯一。旧成员按冻结原始种群中的顺序选各类首9/8个，不按质量事后挑选；20%档的旧成员是10%档的子集。新成员每家族构造20个，10%复用前10个；PORTFOLIO复用同一库，不重复收费。

TOU/DEMAND在逐job路径选择中给归一化Flow项固定0.1权重。BILL循环四个权重。资源可行路径的代价范围以内5%为随机受限候选表。FCFS随机tie、release内SPT、release内LPT随机选一种顺序；这是研究方案的一部分，并非独立识别纯电价评分的因果效应。RESAMPLE为原Random顺序，故本批验证整个构造配方，不能将差异完全归因于费用项。

前缀不是对未来完整解的边际Bill预测。各machine active区间按并集收费，idle按所有实例与实际前缀horizon收费。增量积分只服务构造评分，最终仍由原SSGS构造完整schedule；构造的start需与原SSGS一致，全部新候选独立完整exact重复复验并检查费用分解。原父个体也重新SSGS/exact回放，最终十个种群共1000个代表逐项复验。

每新库位置使用1或4个不同候选的固定完整exact筛选预算。技术预跑只按耗时和内存决定1/4，不能读取质量后选择预算；正式矩阵冻结后不改。随机对照使用同样候选数，但CPU成本不同，不能称等时间比较。所有已评价候选的费用、Flow、来源、构造评分数量都保留数值日志；最终库保留完整解，非胜出候选不存完整genes，可用冻结输入/源码/种子重建。额外库生成成本只记录一次，不把复用的种群伪装成独立构造。

## 配对数据与窗口

从冻结第二步源5bb6668的本地完整raw复制36个诊断base，包含50/100/200任务、六场景、native H/T输入以及原100成员父种群。已有RAW/TIME16/TIME64/STRUCT16/STRUCT64均不重跑。

技术预跑使用旧独立pilot的H/T各一个base/规模，最多两节点12个块，与正式诊断base分开。正式优先seed11001/11002，即144块、1440个新种群；如果按技术耗时及资源保守估计不能在北京时间2026-10-12 08:00前完成，改为只用预定11001，即72块、720个新种群。不得按结果或易例挑选，全部36base与H/T保留。

两当前节点各最多8个本实验worker，nice降低本实验优先级、单worker虚拟内存256MiB上限、保留至少2GiB加一个worker的派发余量。只读取Lilanxin进程与资源，不操作其PID、文件、配置、优先级、cache或训练。使用独立目录，完整块锁与hash续跑；真实失败停止本实验两shard的新派发，未完成证据保留、不自动重试。原运行失败与完成目录不能混入正式计数。

预计块耗时上界外加90秒须在08:00前才准派发。08:00后不再构造新候选；若共享负载使已派发块超期，保留部分证据并准确报告未完成。截止与资源不能保证外部训练负载稳定，因此这是保守收尾目标。只确认启动便向用户返回ETA，不创建Codex定时监控，不等待结果。

## 验收与后续比较

原输入/父个体、原RAW完成证据、冻结source/runner/spec/seed/主机均绑定SHA256；一个块十组必须同host、所有24项结果文件齐全、最终1000代表exact证据有效，才可正式计数。完整退出/无活跃worker另外核验；不能凭目录数宣布完成。

明早与第二步比较时，使用旧五组加新十组的共同经验非支配union重建相同归一化坐标、HV参考点和IGD+ reference；不直接拼接原报告的旧归一化HV。绘制每算例前沿及Flow/Bill端点、固定P100的ND数、方向覆盖，分解TOU/需量与构造耗时。经验union不是真实Pareto前沿。

独立单位为36base，H/T与可用种子先在base内平均。新增四费用家族两个比例对RAW的HV/IGD+共16项构成主Holm家族；同对应比例RESAMPLE的16项另为次级Holm家族。旧STRUCT16/64与新方案的比较为探索性、明确额外成本和不同动作语义。20k配对cluster bootstrap、100k配对signflip，seed2026101203，按规模分层bootstrap。旧已见诊断base只支持开发诊断；不得宣称全新留出确认、创新性已证或最终迭代性能提升。
