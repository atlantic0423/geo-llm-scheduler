## 轨迹与预算

全部组使用在线 Q42 和原 reward，原混合 P100 初始化、Trigger、birth 替换、A3 tariff 与其他原动作、native shared 随机流。每次调用从同一位置生成候选，没有内部候选链。精确评价后的全部可行候选进入 Archive 并保留为该轨迹历史。探索位置允许退步，BEST 在结束时用同一最终 ideal 和 population maximum 重评起点及所有候选，随后一次原 Polish。next state 来自实际探索位置，真正的末步 terminal。完整物理排程身份用 MS 和开始时间识别；Archive 仍保留项目原 MS/OS/timing 身份。

主档轨迹 exact 额度 $C=30$，扩展档 $C=60$；进入 evaluator 后即消耗，包括不可行评价。每步 $B$ 截到余量，空调用也消耗有限的步数。外层各组使用同样生产 wall，包含实际初始化、距离、历史、Q、构造、SSGS、exact、Archive 与 Polish。结束在 offspring 边界，真实超时逐 run 记录；审计/导出单列，但占三天资源窗口。

分配距离为 MS 改变工序比例；顺序先将 OS 的两次 job 出现还原为 P/D 标签，再算 Kendall 分歧，分母排除不可改变的同 job P→D 对；时序为开始时间差除固定工序时长，逐工序截在 1 后取平均。分别保留三个分量。D4 对前一个 A7/A8 用时序，否则用 MS/OS 最大值。D3 零路径取 0；所有信号只用本轨迹已完成位置，不跨轨迹，不读取未来候选。

独立 W1 校准集为 32 个新父实例，每个 run 90 秒。每 run 每信号固定容量 1024 的显式独立 RNG reservoir，合并样本取 1/3、2/3 顺序统计量；零值/并列原样保留。动态第一步用 6，此后信号不超过低阈值给 3，不超过高阈值给 6，否则 10；D6 反向。C0/L1/A1 复用 D2 阈值。AID 预构造同源候选序列，逐候选 exact，首次可行、物理排程不同且当前共享标量不劣时停止，未发生时仍可退步。预构造的成本与 RNG 消耗也计入。

## 正式前冻结与三阶段

筛选共同参考按同一输入的所有组和 seed 合并经验 ND union，以共同 min/range 归一化，HV reference=(1.1,1.1)，IGD+ 参考同 union，非 true Pareto。先对每父平均版本/seed，再对 D1–D6/A1 计算每父 HV 高优、IGD+ 低优的平均序位；同值用中秩，跨父等权累加两指标序位，最小者入选，完全并列按 ID 字典序。四规模/拓扑/压力矩阵等数，故等父也等权。选择文件连同全部筛选 index 哈希固定后，两确认集都只比较 S0、W1、所选距离组和 R0。R0 的概率来自所选组筛选阶段非首步、剩余额度至少10的请求档位频率；无样本用预设 .4/.3/.3，并匹配 AID 开关。边际分布相同不等于成本相同，仍报告实际成本。

筛选的17对W1×HV/IGD+共34项为探索 Holm 家族；其他机制对照另列探索。确认、long 分开，各预定所选距离对 W1/R0/S0 × 两指标六项 Holm。独立单位为父实例，先平均版本/seed；20000分层 bootstrap、100000配对 sign-flip，统计seed2026101603。报告效应与区间、anytime、端点及成本，不将不显著当等价。退步后的突破/截尾在同一轨迹最终固定 context 下描述，完整轨迹每run固定容量3的随机 reservoir，不能按成功筛选。

## 执行与恢复边界

`campaign.prepare` 冻结全部输入和原初始化指纹；两个 `campaign.supervise` 持独占锁、只派发各自父实例。两个节点全部 screen 完成且 index 身份通过后锁定一次选择；confirm 和 long 自动按同选择执行。任一失败写共享 stop，只停止新派发，保留失败目录及日志，绝不静默重试。非完整尝试不能成为正式结果。监督器意外退出不冒称可从算法内部 checkpoint 恢复。

每 worker 单线程、低优先级，Linux AS 上限256MiB；48路时每容器最多24个，共6GiB地址空间上界，并留系统/监督余量。派发另有1GiB cgroup空余、根卷20GiB空余、本批每容器16GiB结果量与共享本批1.5GiB元数据门。完整结果保存在本批独立容器目录，源/输入/轻索引在共享卷；本地回收器按完整标记逐成员 SHA 拉取，不依赖 Codex 对话保持活跃。仅对本批完整结果给出 clean-page fadvise，无磁盘删除。到 T0+72h 前保守预留1.5倍单run预算+300秒，停止新派发，真实截尾单列。估时必须使用技术pilot实测，不能把15%占位当实测。

每run保留 summary、Q42×8/updates/selections、有界轨迹/anytime诊断、逐解流式压缩的完整population+Archive、完整 SHA marker。运行后逐最终成员独立 exact，检查可行性及Flow/Bill，再提交 complete 与共享 index。流式导出避免把整个Archive同时转换为巨大JSON字符串。source head/canonical/clean、输入、配置、初始化、实际hostname均验真；最终回收另做完整 SHA。完成工程/启动不等于已确认任何方案质量收益。

内存空余按 cgroup limit-current 加干净 inactive_file 页估计；脏页、writeback、shmem 不扣除，active_file 不视为可回收余量。该估计配合每 worker 地址空间硬上限使用，不通过删除历史文件或全局 drop_caches 腾空间。统一轻量研究观测也计入生产 wall，报告 observer_seconds；S0 的固定代数行为与原严格轨迹回归核对，但额外研究记账有成本，不能把它称为零开销的原始部署基线。
