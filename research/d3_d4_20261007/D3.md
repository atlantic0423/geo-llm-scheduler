## 结论

**当前 RESPONSE v1 不晋级在线模型。** 三项预定主比较都未通过联合门槛；相对 BASE、RGAIN 的点估计为负，相对容量匹配 SHUFFLED 的差值接近零。没有证据表明这组机会与权重交互项，在已有质量/历史/阶段等控制之外，提供稳定增益。这个结论限定于固定候选生成、六个邻域位置、固定 ridge 表示和当前标签，不等于所有 MOEA/D 方向改进均无效。

## 冻结设计与完整性

48 个新 base，50/100 jobs 各 24 个；前 16+16 个用于开发，后 8+8 个作为完整留出。H/T 电价、三个 seed、10%/50%/90% 阶段、三个偏好，合计 288 source+288 probe、2592 panel、124416 方向/动作行；留出决策 6912 条，每 base 432 条。每个动作 A1–A8 仅生成一次原 B3 候选池，各策略在同池内选择六个位置；目标权重不进入候选构造。

每动作固定 alpha=1 ridge，尺度拟合和标签训练仅使用 32 开发 base。RESPONSE 在 BASE 上增加机会与权重/权重平方交互；SHUFFLED 在匹配任务数、阶段、偏好、动作的不同 panel 间打乱机会，保持表示容量。POST_RGAIN 使用生成后信息，是事后同池上界，不能作为前瞻算法。

16 个独立留出 base 等权；每 base 内阶段、动作、电价、seed 等权。原协议的 20000 次 base bootstrap、全部 65536 次双侧符号翻转、三比较 Holm 保持不变。要求三项均满足均值至少 0.001、95% CI 下界大于零、Holm $p<0.05$。

两 shard 原 validator 全通过，输入与初始化/配置/协议/源码 hash 相符；每对 source/probe 保持同 host；退出 complete，无活跃 worker、无失败。原 worker 证据支持 192962 次 source 最终 exact 与 95182 次 probe 审计；本批再次验证冻结产物和逐文件 SHA，未把这些计数说成全部重新执行 exact。

完整原件 8612 文件、7796038850 字节；tar.gz 549201296 字节，SHA256 `9d741561925c5cf49e369e7efb8b8e1bcad9312a82dd52c80528862b940aa985`，每一成员和每一本地文件对清单验证。服务器原件保留，中断/锁/运维历史一起归档。源码 bundle 和完整输入/产物可复现包随 Release 交付。

## 门槛尺度与局部现象

POST_RGAIN 在每一留出决策均不低于任何前瞻策略，独立 CSV 检查通过。它相对 BASE 的平均空间只有 5.44662352e-05，相对 RGAIN 为 5.08076138e-05。所以当前观测候选池即使事后完美选择，也达不到 0.001 的主比较门槛。**这暴露了门槛的标签尺度校准问题，不解除当前 v1 的不晋级结论**：点估计本身也没有稳定超过控制。若将来重启方向研究，必须先在独立开发数据估计上界与实用收益，并为新留出冻结新协议，不回调本批门槛。

RESPONSE 与 BASE 选择同一 index 的比例为 76.97%，与 SHUFFLED 为 86.50%；多数选择并未改变。50 jobs 的 RESPONSE−BASE 为 -6.4451e-06，100 jobs 为 +3.1220e-06，存在异质性，不能解释为普遍提升。早期 s0 为 -9.0001e-06、后期 s2 为 +4.3419e-06，同样仅为探索描述。
